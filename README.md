## 🤝 CÓMO COLABORAR EN ESTE REPOSITORIO

1. Clonar: `git clone git@github.com:In-Silico-RG/SICVEC_2026.git`
2. Antes de trabajar: `git pull`
3. Guardar cambios: `git add -A && git commit -m "Descripción corta del cambio" && git push`
4. Las tareas se llevan en `08_Cronograma/Seguimiento/TAREAS.md`; marcar `[x]` al completar.
5. Cotizaciones, contratos y planos van en la subcarpeta correspondiente de `06_Logistica/`.
6. Los PDF se regeneran desde el `.tex` con `pdflatex` (dos pasadas). No subir archivos `.aux/.log/.out` (ya están en `.gitignore`).
