# reviews/

External reviews of project documents, archived verbatim in the language received, one
file per review event: `YYYY-MM-DD_<what-was-reviewed>.md`. Each file ends with an
**Adjudication** section: accepted points mapped to the changes they caused (with the
plan revision entry), rejected points with reasons, and anything adopted as a design
constraint. The plan's revision log and `LOG.md` point here; they do not repeat the text.
